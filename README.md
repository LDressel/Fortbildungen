# Fortbildungen

Materialien zu Fortbildungen. Jede Fortbildung liegt in einem eigenen Unterordner, die Startseite `index.html` verlinkt alle.

| Ordner | Fortbildung |
|---|---|
| `ais-chat-grundschule/` | AIS.chat in der Grundschule – Prompt-Sammlung für Lernszenarien und Dialogpartner |

Neue Fortbildung: Ordner anlegen und auf der Startseite eine Kachel ergänzen.

## AIS.chat in der Grundschule

- `index.html` – Seite mit Auswahl Klasse → Fach → Thema
- `data.js` – alle Lernszenarien, Dialogpartner und Lehrkraft-Prompts (hier bearbeiten oder ergänzen)
- `bilder/` – Figurenbilder zum Hochladen in AIS.chat
